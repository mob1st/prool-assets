# Issue Tracker

Linear is the source of truth for planned work in this repository.

## Workflow

- Use the issue identifier and branch name provided by the Linear ticket.
- Do not shorten, rename, or reinterpret the Linear-provided branch name.
- Use the Linear issue identifier in commits, pull requests, and status updates.
- Read the Linear issue before starting work, including its parent, blockers, labels, and acceptance criteria.
- Keep GitHub focused on branch hosting, pull requests, code review, and merge state.
- Do not create or modify GitHub issues unless a user explicitly asks for that workflow.

## Status Updates

When work changes scope, becomes blocked, or satisfies acceptance criteria, update the Linear issue or leave a concise Linear comment with the relevant pull request link.
