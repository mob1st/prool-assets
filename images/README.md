# Images

Public image assets live under this directory.

The directory structure mirrors the public CDN path under `https://assets.playprool.com`.

Use semantic entity paths:

```text
images/country/<country-slug>/tournaments/<tournament-slug>/<asset-kind>/<version>.<ext>
images/country/<country-slug>/teams/<team-slug>/<asset-kind>/<version>.<ext>
```

Examples:

```text
images/country/england/tournaments/premier-league/logo/2026-27.svg
images/country/england/teams/arsenal/jersey/2026-27.svg
```
